🌍 Global-Life-Expectancy-Analysis-Project
This project analyzes global life expectancy data to identify trends, patterns, and disparities across countries, years, and genders. Using Python-based data analytics techniques, the dataset was cleaned, transformed, and explored to generate meaningful insights into population health and longevity.
📊 Tools & Technologies
-Python
-Pandas
-NumPy
-Matplotlib
-Seaborn
-Plotly
🔧 Key Activities
-Performed data cleaning and preprocessing by handling missing values, checking duplicates, and standardizing data formats.
-Applied feature engineering to create life expectancy categories (Low, Medium, High).
-Conducted data transformation using Min-Max Normalization.
-Identified outliers using the Interquartile Range (IQR) method and boxplot visualization.
-Performed Exploratory Data Analysis (EDA) through univariate, bivariate, and multivariate analysis.
-Created interactive and statistical visualizations using Matplotlib, Seaborn, and Plotly.
-Utilized pivot table analysis to uncover trends across countries, years, and gender groups.
